# R2.1 — правки плана и доступность поручений

Основа: `511d6883b0e369becce71d1e02c1170c1ad08abd`. Задача #363; продолжение #360. Схема SQLite, evidence/history, ACL/PIN, поставка и CI не меняются.

## Принятые изменения

Редактор исходной строки сохраняет несохранённый ввод и состав подготовленных задач при переключении строк, фильтров, закрытии редактора и переходе к другому плану в открытой странице. Статус явно отличает правки от сохранённых данных; «Отменить правки» возвращает подтверждённые значения. При уходе со страницы с правками браузер предупреждает о потере ввода. Это не межсессионное хранилище: подтверждённая перезагрузка или аварийное закрытие вкладки его очищает.

Фильтр «Требуют проверки» показывает только такие строки и честное пустое состояние. Редактор получает фокус после выбора строки; закрытие возвращает его к строке. Размеры полей и область нажатия увеличены, вложенные рамки упрощены, уведомление не перехватывает клики по рабочим данным; его кнопки остаются доступны.

Одновременный повтор сохранения подавляется. Пока сохраняется одна строка плана, другую можно редактировать, но её сохранение доступно после ответа предыдущей операции. Отказ POST сохраняет форму и ошибку; поздний ответ не открывает прежний план поверх нового. Уже созданные связанные задачи не убираются из массива по кнопке удаления черновой части — так не переиспользуются их позиции для других задач. Неоднозначные одинаковые ФИО не превращаются в выбранного первого сотрудника.

Поручение открывается независимо от списка документов. Материалы загружаются отдельно, при отказе показываются причина и «Обновить список»; новый файл и выполнение доступны. После завершения используется подтверждённый ответ API, а ошибка обновления обзора не выдаётся за отказ записи. Выбранный, ещё не приложенный файл и комментарий сохраняются при выполнении задачи. Материалы остаются необязательными.

## Делегирование и проверка

Отдельные исходные UX-задания получили специалисты по редактору плана, поручениям/материалам и загрузке документов. В R2.1 реализованы первые две области; замечание к сообщению об ошибке polling загрузки остаётся за пределами этого PR. Изменения свёл интегратор. Независимый аудит выявил гонку параллельных сохранений и неявную ошибку документов; после исправления блокеров по исходникам не найдено. Статический аудит не считается браузерной проверкой.

Новые проверки: `npx playwright test tests/browser/r2-editing.spec.mjs --project=desktop --project=mobile`.
Существующая регрессия: `tests/browser/plan-source-rows.spec.mjs` и `tests/browser/assignment-simple-completion.spec.mjs`, обе компоновки.

12/12 локальных браузерных проверок успешны, без ошибок JavaScript. Для экономии памяти тот же набор утверждений выполнен напрямую через Playwright, без дополнительного процесса runner. Среда, отпечаток исходников и результаты — [R2.1-EVIDENCE.json](R2.1-EVIDENCE.json). Успех GitHub CI и merge подтверждаются в PR после выполнения, не предсказываются здесь.

## Поэлементная граница

Актуализированы индивидуальные записи D2/D4, форм и исходный индекс. Счётчик реестра не означает завершённую приёмку каждого элемента всего проекта. Остальные случаи загрузки, материалов, распоряжений, План / факт и дальнейшие R3–R7 остаются в полном плане. До следующей перерисовки карточка строки, сохранённой в фоне, может сохранять прежнюю краткую отметку; подтверждённый результат доступен в уведомлении и исходном объекте.
