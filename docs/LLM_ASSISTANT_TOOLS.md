# Прикладной модуль «Ассистент кафедры»

Модуль вспомогательных аналитических микро-задач на базе LLM (локальной или удалённой) для Кафедра-планера.

## Назначение

Инструмент ускоряет рутинную обработку неструктурированных фрагментов документов и поиск по архиву без усложнения бизнес-модели приложения:

1. **Анализ текста из буфера (Ad-hoc Text Processing)**:
   * Пользователь вставляет текст (из протокола, письма, проекта отчёта, скана).
   * Модель извлекает упомянутые объекты (поручения со сроками, публикации, персон, протоколы).
   * Вывод: интерактивная таблица с возможностью редактирования ячеек прямо в браузере и копирования в буфер обмена.
2. **Поиск по архиву заседаний (Archive Natural Language Query)**:
   * Естественный запрос (например: «Где обсуждалась статья о влажности почв?»).
   * Сервер выполняет полнотекстовый поиск SQLite FTS5 с фильтрацией по правам доступа (ACL).
   * Модель сопоставляет кандидатов, выделяет номера заседаний, протоколов, вопросов и точные цитаты.
3. **Формулы для LibreOffice Calc и Excel**:
   * Пользователь описывает расчёт («как подтянуть должность по ФИО через ВПР», «подсчёт часов преподавателя за семестр»).
   * Модель возвращает готовую формулу с русской локализацией функций (`ВПР`, `СУММЕСЛИМН`) и точкой с запятой `;` в качестве разделителя, а также краткую инструкцию.

## Интерфейс и доступ

* **Кнопка в шапке**: `✨ Ассистент` рядом с глобальным поиском.
* **Горячая клавиша**: `Alt + A` (или `Ctrl + Shift + A`) открывает выдвижную боковую панель (Drawer) поверх любого раздела без потери контекста.
* **Быстрый запуск**: `Ctrl + Enter` (или `Cmd + Enter`) в поле ввода.
* **Закрытие**: `Esc` или клик по фону.

## Умный экспорт и редактирование

* **Инлайн-правка ячеек**: кликните любую ячейку в таблице результатов, чтобы скорректировать распознанные данные до экспорта.
* **Кнопка «📋 Скопировать в Excel / Calc»**: помещает в буфер обмена формат `text/tab-separated-values` (TSV) и `text/html`. При вставке (`Ctrl + V`) в LibreOffice Calc или MS Excel данные раскладываются строго по столбцам и строкам без смещений.
* **Сохранность черновиков и история**:
  * Черновик автоматически сохраняется в `sessionStorage` по мере набора.
  * История последних 15 выполненных запросов сохраняется в `localStorage` браузера с возможностью быстрого восстановления.

## Экономия токенов и безопасность

* **Санитизация**: перед отправкой в модель текст очищается от колонтитулов, пустых строк и артефактов OCR (экономия 25–40% токенов).
* **Кэширование по SHA-256**: повторный запрос с тем же текстом и задачей возвращается мгновенно (0 токенов, 0 мс).
* **Отмена генерации**: кнопка `«Отмена»` прерывает сетевой запрос через `AbortController`, освобождая ресурсы сервера модели.
* **Автономия**: при `KAFEDRA_LLM_ENABLED=false` ассистент сообщает о выключенном режиме, а все остальные функции системы работают штатно.

## API

* `GET /api/assistant/status` — возвращает `{ enabled, configured, model }`.
* `POST /api/assistant/process` — принимает `{ task, text, query }` и возвращает структурированный ответ (`{ status, result, cached, durationMs }`).
