# Учебный процесс и успеваемость

Раздел **«Учебный процесс → Успеваемость»** формирует проверяемую сводку по ведомостям учебных групп. Исходный XLSX, ODS или CSV проходит обычный document intake, сохраняется неизменяемым и остаётся источником каждого извлечённого факта.

## Рабочий сценарий

1. Оператор нажимает **«Загрузить ведомость»** и выбирает файл.
2. Система определяет лист, строку заголовков, колонку со студентом, дисциплины и кандидаты метаполей.
3. Для `Учебного года`, `Семестра` и `Учебной группы` оператор подтверждает один из режимов:
   - **из ячейки таблицы** — выбираются лист и точный адрес ячейки;
   - **ввести вручную** — сохраняется ручное происхождение без фиктивной ссылки на ячейку.
4. Перед импортом показываются выбранные колонки и фрагмент исходной таблицы.
5. Корректные строки импортируются независимо от ошибок других строк.
6. На главном экране ведомости сгруппированы как **учебный год → семестр → группа**.
7. Сводка показывает распределение оценок и средний балл по каждой дисциплине.
8. Для одного учебного периода можно отметить несколько актуальных групп и получить общий итог по дисциплинам; средний балл рассчитывается взвешенно по всем числовым оценкам.
9. Нажатие на дисциплину раскрывает студентов и точные адреса исходных ячеек.

## Актуальные и предыдущие версии

Для одной группы в одном учебном году и семестре существует не более одной актуальной успешно обработанной ведомости.

- Новый успешный импорт становится актуальным и переводит прежний в состояние **«Предыдущая версия»**.
- Ошибка нового импорта не снимает прежнюю актуальную ведомость.
- Архивирование не удаляет исходный документ и извлечённые данные.
- Любую успешно обработанную предыдущую или архивную версию можно сделать актуальной повторно.
- Общая выгрузка и итоги по выбранным группам используют только актуальные активные ведомости, поэтому оценки не удваиваются.

## Правила оценок

- `5`, `отлично`, `отл.` → отлично;
- `4`, `хорошо`, `хор.` → хорошо;
- `3`, `удовлетворительно`, `удовл.` → удовлетворительно;
- `2`, `неудовлетворительно`, `неуд.` → неудовлетворительно;
- `н/а`, `не аттестован`, `неаттестация`, `не зачтено`, `неявка` и эквивалентные явные отметки → не аттестован;
- пустая ячейка и прочерк остаются пустыми и не считаются неаттестацией;
- неизвестный непустой текст сохраняется как требующий проверки и не подменяется оценкой.

Средний балл рассчитывается только по числовым оценкам `2–5` и округляется до двух знаков. Неаттестации, неизвестные и пустые ячейки в среднее не входят. В интерфейсе и CSV используется десятичная запятая.

## Источники и доказательства

Для оценки сохраняются:

- идентификатор неизменяемой версии документа;
- лист;
- строка;
- колонка;
- адрес ячейки;
- исходный текст;
- нормализованная категория;
- правило нормализации.

Для каждого метаполя сохраняются:

- нормализованное и исходное значение;
- режим `cell` или `manual`;
- локатор выбранной ячейки либо явная отметка ручного ввода;
- правило нормализации.

Производная сводка не расширяет ACL исходной ведомости.

## Выгрузка

Доступны:

- CSV UTF-8 с разделителем `;`;
- JSON со сводкой и доказательствами;
- `sources.json` с метаполями, версиями документов, SHA-256 и локаторами ячеек.

CSV сначала содержит строки по каждой группе и дисциплине, затем отдельный раздел `ИТОГИ ПО ДИСЦИПЛИНАМ` для выбранных актуальных групп. JSON содержит те же агрегаты в `report.totals`; `sources.json` сохраняет точный состав выбранных импортов.

Строка общей таблицы содержит:

1. учебный год;
2. семестр;
3. учебную группу;
4. дисциплину;
5. общее количество сохранённых значений;
6. количество оценок по категориям;
7. количество неаттестаций;
8. количество нераспознанных значений;
9. средний балл.

## Хранение и обновление

Схема 031 добавляет самостоятельные сущности групп, учебных периодов, студентов, состава групп, дисциплин, запусков импорта, метаполей, оценок и ошибок. Сводка не хранится вторым источником истины: она вычисляется из `academic_grade_records` актуальных ведомостей.

Резервное копирование и восстановление используют общий SQLite/blob-контур. Исходники, метаполя, оценки, старые версии и их SHA-256 входят в штатную копию без отдельного внешнего сервиса.
