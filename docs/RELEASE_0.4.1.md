# Kafedra Planner 0.4.1

Дата выпуска: 1 сентября 2026 года.

`0.4.1` — корректирующий выпуск автономной системы работы кафедры. Он содержит только изменения, уже слитые в `main`, прошедшие собственный GRACE 4 lifecycle, обязательный CI и post-merge проверку.

## Что изменилось для пользователя

### Надёжная обработка документов

- Unicode-safe загрузка принимает русские, смешанные, emoji и длинные имена документов без ошибки построения HTTP-заголовков.
- Исходное имя, байты, SHA-256, `document_version` и evidence не изменяются транспортной нормализацией.
- Повторный запрос сохраняет идемпотентность и не создаёт второй документ.
- Полный offline bundle до активации проверяет Tesseract, языки `rus` и `eng`, Poppler, LibreOffice и реальный контрольный путь PDF → изображение → OCR.
- Проверенный target-specific package payload сохраняется атомарно в локальном immutable cache.
- `doctor.sh --repair` может повторно использовать этот cache без Интернета и доустановить только отсутствующие возможности.
- Если строгая проверка документа не пройдена, прежний релиз, SQLite и пользовательские данные остаются активными.

### Понятная диагностика Оформлятора

Интерфейс различает безопасные категории ошибок:

- DNS или неверный адрес;
- отказ соединения на порту;
- тайм-аут;
- ошибка TLS/сертификата;
- по адресу отвечает другой сервис;
- Оформлятор запущен, но не готов;
- требуется корректный код доступа.

Неизвестные 5xx не раскрывают stack trace, путь к файлам, удалённый ответ или секреты. Недоступность интеграции не блокирует ручную работу со справочником и остальные разделы.

### Планы: `Текущие | Архив`

На рабочем компьютере основной режим списка планов больше не скрыт в общем выпадающем фильтре:

- `Текущие | Архив` постоянно видны в панели планов;
- переключение выполняется одним кликом либо с клавиатуры;
- используется существующий серверный `status=active|archived`;
- поиск и остальные фильтры сохраняются;
- недоступный в новом наборе detail не остаётся устаревшим;
- пустые состояния различают отсутствие текущих планов и пустой архив;
- control имеет явное выбранное состояние, видимый focus и интерактивную высоту не меньше 44 px;
- анимация для переключения не требуется.

Мобильные режимы не добавлялись. В выпуск не входят отдельная мобильная навигация `список → карточка`, bottom sheet, жесты или mobile-only transitions. На узкой ширине сохраняется прежний совместимый элемент выбора.

## Инженерная надёжность

- GRACE executable assertions используют зафиксированное окружение и выполняют команды утверждённого плана в CI.
- Release-, offline-, systemd-, database-, organization- и science-проверки остаются независимыми обязательными evidence.
- Установка системных пакетов остаётся additive-only: без downgrade, upgrade уже установленного пакета, удаления, `package=version` и автоматического `apt --fix-broken`.
- Docker, CDN, облачный сервис, обязательный Интернет и обязательный LLM не добавлены.
- SQLite schema остаётся `31`; новых миграций в выпуске нет.

## Что намеренно не включено

- закрытые без merge и исторические ветки;
- экспериментальные commits и временные workflow;
- незавершённое обратимое исключение распознанных строк;
- общий редизайн карточки плана и всех вторичных фильтров;
- отдельные мобильные режимы;
- изменение lifecycle, evidence или источников документов;
- обязательное подключение Оформлятора или LLM.

## Обновление существующей установки

Используйте full bundle, собранный для той же серии и архитектуры Debian/Astra Linux, что и целевая машина:

```bash
sudo ./install-kafedra-planner.sh
```

Обновление выполняет проверку bundle, создаёт и проверяет резервную копию перед изменяющей миграцией/переключением, использует immutable release directory и проверяет API, worker и document runtime. При ошибке применяется штатный rollback; destructive reset существующей базы запрещён.

После установки:

```bash
sudo /opt/kafedra-planner/current/scripts/offline/doctor.sh
```

Восстановление document runtime из сохранённого offline payload:

```bash
sudo /opt/kafedra-planner/current/scripts/offline/doctor.sh --repair
```

## Совместимость

- Node.js: поддерживаемый embedded/runtime контракт проекта;
- основное хранилище: SQLite schema `31`;
- целевые ОС: Debian 12 и совместимые проверяемые профили Astra Linux;
- автономная работа без Docker, CDN, облака и обязательного LLM;
- bundle одной серии ОС нельзя переносить на другую серию либо архитектуру.

## Проверка артефактов

Рядом с full bundle публикуется файл SHA-256. Перед установкой проверьте его стандартной командой:

```bash
sha256sum -c kafedra-planner-0.4.1-*.tar.gz.sha256
```

Релиз считается опубликованным только когда tag `v0.4.1`, commit `main`, версия внутри manifest и имена артефактов согласованы, а GitHub Release не является draft или prerelease.
