# R8: дополнительные профили протоколов

Основной контракт заседаний остаётся в `docs/MEETINGS.md`. Дополнительное распознавание повторяющихся кафедральных форматов описано в [`PROTOCOL_PROFILES.md`](PROTOCOL_PROFILES.md).

Профиль расширяет детерминированный `department_protocol` parser, не заменяя его, не требуя LLM и не изменяя immutable source. Реальная двухдокументная приёмка отслеживается в Issue #326.
