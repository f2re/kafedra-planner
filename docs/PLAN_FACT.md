# План / факт, ручные корректировки и экспорт

Версия контура: `0.1.0-alpha.9`.

## Назначение

Контур переводит поручения и периодические обязанности из простого списка сроков в проверяемую картину исполнения:

```text
поручение → плановый показатель → отчёт → фактический показатель
→ проверка руководителем → план/факт → риск и персональное уведомление
```

## Извлечение показателей

Детерминированный обработчик распознаёт:

- строки вида `Показатель: ...; план: ...; факт: ...`;
- формулировки `выполнено 6 из 10 мероприятий`;
- целевые значения `не менее 5 статей ВАК`;
- составные поручения вида `подготовить показатель и представить отчёт`;
- явный процент готовности;
- состояния: выполнено, частично, перенесено, отменено.

Плановые значения берутся из ожидаемого результата и текста поручения. Фактические значения сохраняются отдельно для каждой версии отчёта. Исходные документы и локаторы доказательств не изменяются.

## Подтверждение и ревизии

Отчёт может содержать несколько показателей и несколько последовательных версий. Каждая связь отчёта с поручением получает собственный результат и набор фактических наблюдений. Возврат руководителя не удаляет предыдущую версию, а подтверждение отмечает, какой результат принят.

## Ручная корректировка числовых показателей

Оператор может исправить числовой план или факт непосредственно в карточке поручения.

При исправлении обязательно сохраняются:

- исходное машинное значение;
- новое эффективное значение;
- причина;
- сотрудник, внёсший изменение;
- версия отчёта для фактического показателя;
- дата и время;
- связь с предыдущим исправлением.

Журнал является добавочным. Повторное исправление не удаляет предыдущую запись, а помечает её заменённой. Отмена текущего исправления восстанавливает предыдущее действующее значение, а при его отсутствии — машинный результат.

Ручное значение участвует в расчёте отклонения, процента исполнения, среднего прогресса и экспорта. Исходный документ и результат автоматического извлечения не переписываются.

## Персональная выборка

Экран «План / факт» показывает:

- задачи выбранного сотрудника;
- задачи, контролируемые руководителем;
- план и факт по каждому показателю;
- процент исполнения;
- просрочки, риск срыва и доработку;
- семестровые, учебные, календарные и квартальные задачи.

Справочник профилей перечитывается при каждом открытии экрана, поэтому импортированные или созданные в текущем сеансе сотрудники доступны без перезагрузки страницы.

Состояние уведомления хранится раздельно для каждого сотрудника. Прочтение сообщения руководителем не скрывает его у исполнителя.

## Сохранённые представления

Текущий набор фильтров можно сохранить под понятным названием. Сохраняются:

- режим: кафедра, задачи сотрудника или контроль руководителя;
- сотрудник;
- диапазон дат;
- направление;
- состояние;
- вид и ключ периода.

Представление может быть личным или общим для кафедры. Повторное сохранение под тем же именем обновляет фильтры без создания дубля.

## Экспорт

Доступны два формата:

- CSV UTF-8 с разделителем `;`, пригодный для Excel и отечественных офисных пакетов;
- JSON с полной структурой карточек, метрик, исправлений и итоговой сводкой.

CSV содержит эффективные и машинные значения, признак ручного исправления и его причину. Экспорт использует активные фильтры экрана.

## Оценка риска

Риск рассчитывается детерминированно по сроку, дате начала и последнему известному прогрессу. Система различает:

- по плану;
- срок приближается;
- риск срыва;
- просрочено;
- отчёт ожидает проверки;
- требуется доработка;
- выполнено.

Оценка риска не закрывает поручение автоматически и не заменяет решение руководителя.

## Проверка пользовательских потоков

Chromium-сценарии основного интерфейса, научного реестра и план/факт используют отдельные временные SQLite-базы и разные порты. Состояние одного сценария не влияет на другой, при этом Chromium устанавливается один раз в CI.

Контур план/факт проверяет полный путь:

```text
поручение → отчёт → подтверждение → ручное исправление
→ журнал → сохранённый вид → CSV/JSON → отмена исправления
```
