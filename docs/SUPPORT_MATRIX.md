# Матрица совместимости

Ни один профиль пока не имеет статуса промышленно проверенного.

| Профиль | Runtime | Состояние | Требуемое доказательство |
|---|---|---|---|
| разработка Linux x86-64 | Node.js 22.16+ | частично проверено | автоматические тесты |
| Debian 12 x86-64 | Node.js 24.18.0 | ожидает акта | install, DOCX/PDF, restart, backup/restore |
| Astra Linux 1.7 x86-64 | Node.js 24.18.0 | ожидает акта | точный update, glibc, системные пакеты, полный офлайн-тест |
| Astra Linux 1.8 x86-64 | Node.js 24.18.0 | ожидает акта | точный update, glibc, системные пакеты, полный офлайн-тест |

Поддержка конкретной ОС не объявляется на основании совместимости исходного кода. Нужен акт с SHA-256 комплекта, Git commit, версией схемы, версиями Node.js, SQLite, LibreOffice, Poppler и Tesseract.
