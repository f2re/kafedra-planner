# Kafedra Planner 0.3.4

## Главное

Версия `0.3.4` развивает два законченных пользовательских сценария: визуальную настройку DOCX-шаблонов заседаний и сетевой импорт сотрудников из Оформлятора с явным выбором переносимых полей. Схема SQLite повышена до `29`.

## Оформлятор: выбор полей сотрудников

После проверки адреса и порта Kafedra Planner читает определения полей выбранного пространства Оформлятора. ФИО переносится всегда. Для стандартных колонок локального справочника можно отдельно назначить источник для `E-mail` и `Должность`; система предлагает наиболее вероятные поля по стабильному ключу, подписи и aliases, но окончательный выбор остаётся за оператором.

Дополнительные свойства — телефон, подразделение, учёная степень и любые другие поля типа `person` — выбираются чекбоксами. Их значения хранятся отдельно от базовой таблицы `people` вместе с исходным `remote employee id`, ключом и подписью свойства. Повторная синхронизация обновляет ту же запись и не создаёт дубль.

Перед изменением локальных данных выбранные ключи сверяются с текущими property definitions Оформлятора. Если поле было удалено или переименовано, импорт останавливается с понятным конфликтом вместо тихой потери данных. Профили сотрудников загружаются ограниченным параллелизмом, сетевые запросы выполняются до SQLite-транзакции, а четырёхзначный код доступа по-прежнему не сохраняется.

Migration `029` добавляет только таблицу настройки field mapping и таблицу значений дополнительных свойств. Обновление `28 → 29` не перестраивает `people`, `docomator_integrations` или существующие внешние связи.

## Заседания: визуальный DOCX-шаблонизатор

В выпуск также входит визуальный редактор шаблонов заседаний, реализованный после `0.3.3`. Оператор может загрузить обычный DOCX без специальных служебных маркеров, выбрать повторяемые участки и поля в браузере и сохранить профиль генерации. При формировании протокола/выписки сохраняются исходные OOXML-стили, форматирование, нумерация и структура повторяемых строк/абзацев; совместимость с прежним `{{AGENDA}}` сохраняется.

## Проверки выпуска

Release gate `0.3.4` дополнительно проверяет:

- upgrade `28 → 29` без потери существующих сотрудников и связей Оформлятора;
- discovery property definitions и фильтрацию свойств, применимых к `person`;
- автоматическое предложение полей e-mail/должности и явный выбор дополнительных полей;
- загрузку профилей, идемпотентный повторный импорт и обновление дополнительного значения;
- отказ при исчезновении выбранного remote property;
- desktop/mobile browser flow выбора полей перед импортом;
- визуальный редактор DOCX-шаблонов заседаний;
- существующие планы, автоматические назначения, lifecycle документов, backup/restore и полный offline bundle.

После успешных post-merge gates GitHub Actions собирает полный автономный bundle, установщик, пакет F2RE Project Control и SHA-256 и публикует тег `v0.3.4`.
