# Kafedra Planner 0.3.0

## Главное

Версия 0.3.0 завершает рабочий контур планов кафедры: Word-документ разбирается на проверяемые исходные строки, одна строка может быть преобразована в несколько задач, а документ или план можно безопасно архивировать и связать с логическим преемником без подмены исторических источников.

## Импорт планов из Word

- исправлена загрузка файлов с кириллическими именами в браузере;
- сохраняются исходные таблицы, строки, ячейки, locator и evidence;
- пустая ячейка больше не сдвигает соседние колонки при распознавании;
- неизвестные колонки сохраняются и могут быть перенесены в комментарий;
- одна исходная строка раскладывается в одну или несколько задач;
- для задач поддерживаются сроки, направления, ответственные, соисполнители и контролёр;
- повторное сохранение идемпотентно и не удаляет существующие поручения молча;
- добавлен адаптивный desktop/mobile экран разбора строк плана.

## Документы и планы

- рабочие и архивные объекты разделены в интерфейсе;
- внутренние типы документов отображаются понятными русскими названиями;
- доступны переименование и уточнение вида документа без изменения исходного файла;
- перед архивированием показывается влияние на пункты, календарь, поручения, отчёты и другие связи;
- архивирование обратимо;
- новый документ или план можно указать как логического преемника;
- self-reference, другой workspace и циклическая цепочка замен блокируются;
- исходные blob, document_version, evidence, plan_item и подтверждённые факты не перепривязываются.

## Схема и обновление

- текущая схема SQLite: **27**;
- миграция 26 → 27 аддитивна;
- обновление выполняется штатным транзакционным установщиком с резервной копией и автоматическим откатом при ошибке;
- основной сценарий не требует Интернета, Docker или обязательной LLM на целевой системе.

## Артефакты выпуска

GitHub Release содержит:

- полный автономный bundle для поддерживаемой Debian/Astra-системы;
- установщик `install-kafedra-planner.sh`;
- краткую инструкцию `README-INSTALL.txt`;
- пакет обновления для F2RE Project Control;
- отдельные SHA-256-файлы и общий `SHA256SUMS`.

Перед установкой проверьте контрольные суммы:

```bash
sha256sum -c SHA256SUMS
```

Для существующей установки используйте тот же штатный установщик: он создаёт проверенную резервную копию, применяет миграции по порядку и переключает версию атомарно.
