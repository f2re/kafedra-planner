# Kafedra Planner 0.3.3

## Главное

Выпуск добавляет сетевую интеграцию с Оформлятором для переноса сотрудников в Kafedra Planner. Подключение настраивается по адресу и порту, проверяется до импорта и не требует ручного копирования списков людей.

## Импорт сотрудников из Оформлятора

- в настройках структуры кафедры появился блок «Импорт из Оформлятора»;
- поддерживаются HTTP/HTTPS, имя хоста или IP и произвольный TCP-порт; стандартное значение — `8080`;
- проверка соединения разделяет три уровня: процесс отвечает (`/healthz`), runtime/БД готовы (`/readyz`), прикладные данные сотрудников действительно читаются;
- если Оформлятор защищён четырёхзначным кодом доступа, Kafedra Planner запрашивает его только для текущей операции и не сохраняет код в БД, конфигурации или журнале;
- после подключения можно выбрать пространство и конкретную группу либо импортировать всех сотрудников пространства;
- перед импортом показываются количество найденных записей и предварительный список ФИО;
- при необходимости можно включить неактивных сотрудников.

Интеграция рассчитана на текущий API Оформлятора с реестром пространств, групп и сотрудников; при несовместимом формате ответа Kafedra Planner показывает отдельную ошибку совместимости вместо частичного импорта.

## Без дублей и без разрушения истории

Каждый импортированный сотрудник связывается с исходным `employee id` Оформлятора. При первой синхронизации существующая запись Kafedra Planner может быть сопоставлена по нормализованному ФИО. Последующие синхронизации обновляют уже связанную запись и не создают новый дубль.

Импорт не удаляет локальные задачи, планы, отчёты, назначения и исторические связи. Смена ФИО или статуса связанного сотрудника синхронизируется на той же локальной записи.

## Хранение и безопасность

Schema `028` добавляет только таблицы параметров интеграции и внешних связей. Исходные предметные таблицы не перестраиваются. Сетевые запросы выполняются сервером Kafedra Planner с таймаутом и без перехода по HTTP redirects; разрешены только `http` и `https`.

Код доступа Оформлятора в сохранённые настройки не входит.

## Проверки выпуска

Release gate проверяет:

- обновление schema `27 → 28` с сохранением существующих сотрудников;
- health/readiness/auth/data flow через mock Оформлятора;
- первый и повторный импорт без дублей;
- обновление ФИО уже связанного сотрудника;
- обработку неактивной записи;
- desktop/mobile browser flow адрес → порт → проверка → пространство → группа → импорт;
- существующие планы, автоматические назначения, lifecycle документов, backup/restore и полный offline bundle.

Полный GitHub Release содержит автономный Debian 12 bundle, установщик, install guide, F2RE Project Control package и SHA-256 контрольные суммы.
