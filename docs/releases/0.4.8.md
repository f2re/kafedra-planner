# Kafedra Planner 0.4.8

Изменения относительно `v0.4.7`. Схема SQLite остаётся **31**. Выпуск добавляет прикладной интерфейсный модуль «Ассистент кафедры» на базе LLM для микро-задач (извлечение таблиц, поиск по архиву, формулы Calc/Excel, поиск пропусков и устранение ошибок), управление и диагностику подключения к LLM из веб-интерфейса, а также исправления сборки автономных пакетов для Astra Linux.

## Прикладной ассистент кафедры

* **Боковая панель (Drawer)**: быстрый вызов по кнопке `✨` в шапке или горячей клавише `Alt + A`, выполнение по `Ctrl + Enter`, закрытие по `Esc` без потери рабочего контекста.
* **Анализ текста из буфера (`table-extract`)**: извлечение структурированных таблиц (поручения, персоны, публикации) из произвольного неформатированного текста с возможностью редактирования ячеек прямо в браузере.
* **Поиск пропусков и исправление ошибок (`gap-repair`)**: анализ текста заседаний, протоколов или сообщений об ошибках; выявление пропущенных дат, номеров пунктов, докладчиков и ответственных с привязкой к проверяемым цитатам (`sourceQuote`) и конкретными рекомендациями оператору.
* **Поиск по архиву заседаний (`archive-query`)**: естественно-языковой поиск по полнотекстовому индексу SQLite FTS5 с фильтрацией по правам доступа (ACL) и точными цитатами.
* **Формулы для Calc и Excel (`formula-calc`)**: генерация локализованных формул с русскими именами функций (`ВПР`, `СУММЕСЛИМН`) и точкой с запятой `;` в качестве разделителя.
* **Умный экспорт**: двухформатное копирование в буфер обмена (`text/tab-separated-values` и `text/html`) для мгновенной вставки в LibreOffice Calc / MS Excel без смещения столбцов.

## Настройка и проверка связи с LLM

* **Индикатор в интерфейсе**: значок в шапке панели показывает реальное состояние сервера модели (`● В сети (42 мс)`, `● Недоступен`, `○ Выключен`).
* **Панель настроек (⚙)**: оператор может проверить связь с сервером модели в реальном времени, указать URL (`http://remote-server:8000/v1`), модель и токен без перезапуска сервера и без ручной правки переменных окружения (настройки сохраняются в `data/llm-settings.json`).

## Совместимость с Astra Linux и автономный комплект

* **Сборщик пакетов ОС**: устранена блокировка `apt-get check` без прав root при создании автономного замыкания зависимостей.
* **Системный preflight**: нормализован поиск системных утилит `runuser` и `useradd` в стандартных путях `/usr/sbin` и `/sbin`.
* **Доступность и сенсорное управление**: все интерактивные элементы оптимизированы под мобильные экраны (сенсорные цели >= 44px), анимация автоматически отключается при `prefers-reduced-motion`.

## Установка и обновление

Выпуск полностью автономен и совместим с Debian 12, Astra Linux 1.7 и Astra Linux 1.8 (`amd64`). Обновление со схемы 31 выполняется без изменения структуры базы данных.
