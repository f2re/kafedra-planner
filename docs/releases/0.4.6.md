# Kafedra Planner 0.4.6

Изменения после `v0.4.5`: поставка для Astra Linux и проверка обновления. Схема SQLite остаётся **31**; новые миграции и изменения модели доступа не добавлены. Заседания, массовый импорт протоколов, редактирование, архивирование и перенос вопросов из `0.4.5` сохранены.

## Автономные комплекты

Выпуск содержит отдельные архивы для Debian 12, Astra Linux 1.7 и Astra Linux 1.8, архитектура `amd64`. Для каждой системы пакеты собираются в соответствующей эталонной среде. В комплект входят Node.js, Python, Tesseract с русским и английским языками, Poppler, LibreOffice и их зависимости.

Общий установщик выбирает совместимый архив по встроенному профилю ОС, а не по имени файла. Отсутствие подходящего архива или несколько одинаково подходящих архивов останавливают установку до изменений системы. Debian-архив не используется вместо Astra-архива.

Сохраняется политика установки только недостающих возможностей: без замены установленных системных пакетов, принудительного понижения версий и автоматического `apt --fix-broken`. При несовместимом пакетном окружении установщик останавливается, а не исправляет ОС за пользователя.

## Проверки выпуска

Проверка Astra UBI запускается без контейнерного PARSEC-bootstrap, с отключённой сетью. Команды передаются без повреждения кавычек; ошибки сохраняют исходный код завершения и диагностику. Проверяются результат OCR и реальное преобразование документа в PDF с последующим чтением текста.

Исправлена подготовка PIN в проверке обновления: используется база установленного приложения, ошибка сброса PIN больше не маскируется удалением временного файла.

Штатный процесс выпуска проверяет обновление с предыдущего опубликованного Debian-комплекта. Искусственный отказ нового worker после переключения `current` должен вернуть прежний выпуск, PIN, конфигурацию и контрольный файл. После снятия отказа проверяются успешное обновление и целостность SQLite. Проверяемый архив не изменяется и не пересобирается перед публикацией.

Версии сверяются с документацией; основной набор тестов выполняется на штатном Node.js, а запуск дополнительно проверяется на минимальной поддерживаемой версии `24.15.0`.

## Установка и обновление

Скачайте архив для своей ОС, соответствующий `.sha256`, `install-kafedra-planner.sh` и `README-INSTALL.txt` в одну папку. Посмотреть выбор установщика без изменения системы:

```bash
bash ./install-kafedra-planner.sh --print-selection
```

Установка или обновление выполняются одной командой:

```bash
sudo KAFEDRA_APT_MODE=bundle bash ./install-kafedra-planner.sh
```

Не запускайте внутренний `install.sh` после ручной распаковки. Исходная папка остаётся пользовательской; установленный код принадлежит root, рабочие данные сохраняются в `/var/lib/kafedra-planner`.

Для каждой ОС также приложен пакет Project Control, созданный из того же проверенного архива. Все файлы перечислены в `SHA256SUMS`. Предыдущие опубликованные версии не перезаписываются.

## Граница подтверждённой совместимости

Astra UBI проверяет пользовательскую среду, пакеты и обработку документов, но не заменяет приёмку на реальном ядре Astra Linux с systemd и PARSEC. Эксплуатационная приёмка остаётся в issue #27 по `docs/TARGET_ACCEPTANCE.md`; реальные протоколы проверяются после установки выпуска. Astra Linux 1.6 не входит в матрицу готовых архивов этого выпуска.
