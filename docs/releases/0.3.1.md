# Kafedra Planner 0.3.1

## Главное

Patch release оформляет Kafedra Planner как самостоятельный GitHub-проект и
публикует проверяемый full offline bundle для установки без доступа к Internet.
Предметные данные, схема SQLite и deployment contract остаются совместимыми с
`0.3.0`.

## GitHub и документация

- главная страница получила CI/release/license badges и быстрые ссылки на
  скачивание, установку, документацию и security policy;
- добавлены MIT license, contributor guide, русская и английская точки входа;
- GitHub Release содержит normal offline bundle, installer, install guide,
  F2RE Project Control package, отдельные SHA-256 и общий `SHA256SUMS`;
- release guide описывает проверку asset-ов, совместимость bundle и штатное
  обновление;
- generated install guide и offline documentation согласованы с PIN-first
  onboarding: при первом открытии пользователь сам задаёт PIN.

## Проверка

Перед установкой скачайте `SHA256SUMS` и необходимые files release, затем
выполните:

```bash
sha256sum -c --strict SHA256SUMS
sudo KAFEDRA_APT_MODE=bundle ./install-kafedra-planner.sh
```

Установщик проверяет archive, manifest и OS profile, создаёт pre-update backup,
выполняет миграции и при неуспешном health-check автоматически возвращает
предыдущее рабочее состояние.
