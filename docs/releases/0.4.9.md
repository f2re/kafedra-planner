# Kafedra Planner 0.4.9

Изменения относительно `v0.4.8`. Схема SQLite остаётся **31**. Выпуск устраняет тупиковые состояния при усвоении нераспознанных протоколов, внедряет фоновый автоматический подбор решений ИИ в разделе проверки данных, добавляет прямой fallback для надёжной установки OCR в Astra Linux при зафиксированных версиях пакетов и расширяет возможности прикладного ассистента кафедры.

## Фоновый ИИ-анализ и исправление замечаний

* **Автоматический подбор решений в «Проверке данных»**: при открытии раздела система в фоновом режиме опрашивает ассистента для всех нерешённых вопросов, подставляя извлечённые реквизиты (номера протоколов, даты, докладчики) с указанием цитаты источника и процента уверенности.
* **Массовый запуск («✨ Подобрать через ИИ для всех»)**: кнопка в шапке раздела запускает принудительную перепроверку всех карточек с живой индикацией прогресса.
* **Просмотр контекста документа**: каждая карточка проверки снабжена ссылкой на оригинальный файл и раскрывающимся блоком с фрагментом распознанного текста для быстрого визуального контроля оператором.

## Усвоение и ручная приёмка нераспознанных протоколов

* **Устранение тупикового состояния**: документы, вызвавшие ошибку распознавания скана или не содержащие структурированного протокольного слоя, больше не блокируют процесс.
* **Кнопка «Ввести реквизиты»**: прямо из списка импорта протоколов оператор может открыть форму ввода метаданных (`editHeaders`) для непринятого файла.
* **Автоматическая материализация заседания**: сохранение введённых оператором данных автоматически создаёт карточку заседания в БД, связывает её с версией документа, переводит документ в статус `processed`, индексирует для поиска и закрывает открытые замечания в проверке данных.

## Надёжная установка OCR и пакетов ОС (Astra Linux 1.7 / 1.8 / Debian)

* **Прямой dpkg fallback**: если штатный APT или проверка зависимостей блокируются из-за зафиксированных версий сторонних системных пакетов, установщик автоматически проверяет возможность безопасной установки недостающих утилит (`tesseract-ocr`, языковые пакеты, `poppler-utils`) напрямую через `dpkg -i`.
* **Согласование через `--fix-packages`**: при наличии пакетного кэша конфликтующие версии библиотек согласовываются без обязательного доступа к Интернету.
* **Диагностика и автолечение (`doctor.sh --repair`)**: восстановление работоспособности OCR теперь безопасно выполняет установку компонентов из проверенного автономного payload.

## Прикладной ассистент и удалённый LLM-сервер

* **Специализированные агенты**: реализованы профильные промпты для глубокого поиска (`search-refine`), анализа протоколов (`protocol-analysis`), синтеза годовых отчётов (`report-synthesis`) и нормоконтроля (`compliance-check`).
* **Ненавязчивый нормоконтроль**: замечания по оформлению носят рекомендательный характер с возможностью предварительного просмотра и явного одобрения оператором.
* **Патч-бандл для LLM-сервера (`npm run bundle:patch:llm`)**: формирует готовый архив для актуализации агентов и инструкций на удалённой виртуальной машине с LLM.

## Установка и обновление

Выпуск полностью автономен и совместим с Debian 12, Astra Linux 1.7 и Astra Linux 1.8 (`amd64`). Обновление со схемы 31 выполняется без изменения структуры базы данных.
