# Отчёты, подтверждение руководителем и научный реестр

## Замкнутый цикл обязательства

```text
основание / пункт плана
→ поручение
→ исполнитель
→ отчёт
→ сопоставление
→ подтверждение руководителем или возврат
→ подтверждённый результат
→ план / факт
```

Новый отчёт не закрывает поручение автоматически. Система может предложить связь по детерминированным признакам; пользователь подтверждает сопоставление, после чего руководитель принимает результат либо возвращает его на доработку.

## Достоверность

- исходный отчёт остаётся самостоятельным immutable document/version;
- машинное предложение связи и его причины сохраняются;
- принятое/отклонённое решение хранится отдельно;
- подтверждение не уничтожает прежние отчёты и ревизии;
- календарная задача закрывается только по предметному переходу состояния;
- возврат снова делает обязательство рабочим;
- пункт ручного плана и связанное поручение синхронизируются без второго источника истины.

## Научная деятельность

Текущий deterministic extractor поддерживает рабочие карточки статей, конференций, грантов/заявок, патентов, проектов и отчётов НИР. Автоматически извлечённые поля сохраняют источник. Научные материалы используют общий document/evidence/people/search/ACL контур.

Жизненный цикл, исторические аффилиации, массовый импорт и агрегированная научная отчётность включены в 0.2.0; дальнейшее развитие не отменяет требования к исходным доказательствам и ручному подтверждению.
