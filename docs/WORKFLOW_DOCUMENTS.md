# Распорядительные документы, поручения и отчётность

Версия контура: `0.1.0-alpha.6`.

## Главная модель

```text
указ / распоряжение / приказ
→ поручения
→ исполнители и контролирующие
→ сроки и календарь
→ напоминания
→ ход выполнения
→ отчётный документ
→ подтверждение руководителем
```

Исходный PDF или DOCX остаётся неизменяемым. Номер, дата, издатель, направление, пункты, сроки и исполнители сохраняются вместе с локаторами исходных фрагментов и уверенностью извлечения.

## Работа без LLM

Основной режим полностью детерминированный:

- распознавание вида документа по заголовку;
- извлечение номера и русской даты;
- поиск секций `ПРИКАЗЫВАЮ`, `РАСПОРЯЖАЮСЬ`, `ПОРУЧАЮ`, `ОБЯЗЫВАЮ`;
- разбиение нумерованных пунктов;
- поиск срока, исполнителя, контролирующего и ожидаемого результата;
- классификация направления по словарям;
- создание вопросов проверки для пропущенных сроков и неоднозначных сотрудников.

Неполный разбор не блокирует документ и не удаляет уже извлечённые сведения.

## Опциональный llama.cpp

Поддерживается OpenAI-совместимый локальный endpoint llama.cpp server. Он вызывается только после детерминированного разбора и используется для предложения пропущенных полей. Предложение LLM не перезаписывает подтверждённые значения и сохраняется отдельным запуском с моделью, версией промпта, хэшем входа и длительностью.

```text
KAFEDRA_LLM_ENABLED=false
KAFEDRA_LLM_ENDPOINT=http://127.0.0.1:8081
KAFEDRA_LLM_MODEL=local-model
KAFEDRA_LLM_TIMEOUT_MS=45000
KAFEDRA_LLM_MAX_TOKENS=4096
```

Недоступный сервер не влияет на worker.

## Семестровые и годовые задачи

Периодическая задача хранит сотрудника, руководителя, период, срок, направление, ожидаемый результат и требование отчёта. В календаре она выглядит как обычная задача, но уведомления содержат аудиторию: исполнитель и руководитель.

## Поиск

Единый контур поддерживает текст, вид документа, номер, диапазон дат, направление, исполнителя, состояние и период. Слой `entity_facets` рассчитан на последующее подключение планов, отчётов, статей, конференций, проектов и патентов без отдельного поискового механизма.
