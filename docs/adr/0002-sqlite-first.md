# ADR-0002: SQLite как первый источник истины

Статус: принято с условием пересмотра.

## Контекст

Первая установка обслуживает одну кафедру и несколько десятков пользователей через серверный API. Главные риски сейчас — офлайн-поставка, обновление, восстановление и корректность извлечения, а не горизонтальное масштабирование.

## Решение

Использовать серверную SQLite в режиме WAL с внешними ключами, `busy_timeout`, короткими `BEGIN IMMEDIATE`, FTS5 и последовательными миграциями.

Файл базы никогда не открывается клиентами по сетевой папке.

## Условия перехода на PostgreSQL

Решение пересматривается при наличии хотя бы одного подтверждённого условия:

- несколько независимых подразделений с высокой параллельной записью;
- устойчивые блокировки записи при нормативной нагрузке;
- обязательная репликация или горячий резерв;
- аналитические запросы, мешающие операционной работе;
- необходимость серверного векторного индекса большого объёма;
- интеграционные транзакции, требующие PostgreSQL.

Переход выполняется через интерфейс repositories и экспорт канонических записей, а не прямое копирование внутренних таблиц.
