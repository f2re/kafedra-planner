# ADR-0001: Node.js и модульный монолит

Статус: принято.

## Контекст

Система должна работать автономно на Astra Linux, обрабатывать документы, выполнять фоновые задания и постепенно получать новые предметные модули. Docomator уже использует Node.js и показывает, что единый runtime упрощает автономную поставку.

## Решение

Использовать Node.js 24 LTS, ECMAScript modules, один API-процесс и один worker-процесс. Код разделяется по предметным пакетам, но поставляется как одно приложение.

Runtime-ядро первой версии не имеет обязательных внешних npm-зависимостей. Системные преобразователи вызываются через `spawn`/`execFile` без shell.

## Последствия

Положительные:

- один runtime;
- малый offline bundle;
- простая диагностика;
- общие контракты API и worker;
- нет брокера сообщений и контейнерного оркестратора.

Ограничения:

- специализированный ML и OCR удобнее выполнять отдельным Python-адаптером;
- интерфейс первой версии написан без Vue, чтобы не вводить build-зависимости до стабилизации предметного потока;
- при росте команды пакеты можно типизировать TypeScript и собирать заранее, не меняя границы модулей.
