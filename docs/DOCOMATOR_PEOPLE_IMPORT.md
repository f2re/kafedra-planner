# Импорт сотрудников из Оформлятора

Kafedra Planner может подключаться к установленному в локальной сети Оформлятору и переносить его реестр сотрудников в справочник кафедры.

## Где находится настройка

Откройте **Настройки → Структура кафедры → Импорт из Оформлятора**.

Укажите:

- протокол `HTTP` или `HTTPS`;
- адрес сервера, например `192.168.1.50` или `docomator.local`;
- порт; стандартный порт Оформлятора — `8080`;
- при необходимости четырёхзначный код доступа Оформлятора.

Код доступа не записывается в SQLite, конфигурационные файлы или журнал Kafedra Planner. Он используется только для текущего запроса к Оформлятору.

## Что делает «Проверить соединение»

Проверка выполняется сервером Kafedra Planner, поэтому адрес Оформлятора должен быть доступен именно с машины, где запущен Kafedra Planner.

Последовательно проверяются:

1. `/healthz` — процесс Оформлятора отвечает;
2. `/readyz` — база данных и runtime готовы;
3. `/api/v1/spaces` — доступна прикладная информация;
4. после выбора пространства — группы и сотрудники.

Интерфейс различает состояния «сервер недоступен», «сервер запущен, но не готов», «нужен код доступа» и «список сотрудников доступен». HTTP redirects не выполняются.

## Выбор сотрудников

После успешной проверки выберите пространство Оформлятора. Затем можно импортировать:

- всех сотрудников пространства;
- только участников выбранной группы;
- при необходимости включая неактивных сотрудников.

Перед импортом показываются количество найденных сотрудников и короткий предварительный список ФИО.

## Правила синхронизации

Импорт не очищает справочник Kafedra Planner и не удаляет связанные задачи, планы или отчёты.

Для каждого сотрудника сохраняется связь с его `remote employee id` в Оформляторе. При первом импорте существующий сотрудник Kafedra Planner также может быть сопоставлен по нормализованному ФИО. Повторный импорт обновляет уже связанную запись вместо создания дубля.

Если в Оформляторе связанный сотрудник стал неактивным и включён импорт неактивных записей, локальная запись переводится в состояние `inactive`. История назначений и ссылки на сотрудника сохраняются.

## API Kafedra Planner

- `GET /api/integrations/docomator` — сохранённые параметры подключения без кода доступа;
- `PUT /api/integrations/docomator` — сохранить адрес/порт и выбор источника;
- `POST /api/integrations/docomator/check` — проверить доступность и получить пространства/группы/preview;
- `POST /api/integrations/docomator/import` — импортировать выбранный список сотрудников.

Изменяющие операции доступны администратору. При отключённой авторизации применяется обычный локальный режим Kafedra Planner.
