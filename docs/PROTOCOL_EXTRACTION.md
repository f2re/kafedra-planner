# Извлечение протоколов

## Поддерживаемая структура

Текущий обработчик распознаёт русскоязычные протоколы, содержащие сочетание признаков:

- слово «Протокол»;
- заседание или кафедра;
- повестка дня, «Слушали», «Решили» или «Постановили».

Извлекаются:

- номер протокола;
- дата заседания;
- председатель;
- секретарь;
- присутствовавшие;
- нумерованные пункты;
- «Слушали»;
- «Выступили» и «Обсудили»;
- «Решили» и «Постановили»;
- первый найденный срок в решении;
- текст после явной метки «Ответственный».

## Что обработчик не должен предполагать

- упоминание человека не означает ответственность;
- любая дата не является сроком;
- обсуждение не является решением;
- одинаковая фамилия не доказывает тождество людей;
- текст, созданный LLM, не заменяет исходный фрагмент.

## Состояния

Высокая уверенность позволяет автоматически подтвердить только структуру заседания. Ответственный, не сопоставленный со справочником людей, всегда создаёт вопрос оператору.

При неизвестной структуре текст всё равно индексируется и остаётся доступным для поиска.

## Тестовый корпус

Каждый новый вариант протокола должен добавляться как обезличенный fixture с ожидаемым JSON-результатом. Исправление одного шаблона не должно ухудшать ранее поддержанные документы.
