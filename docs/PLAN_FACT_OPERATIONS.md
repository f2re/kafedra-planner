# Работа с исправлениями и экспортом план/факт

Версия: `0.1.0-alpha.9`.

## Когда нужна ручная корректировка

Исправление используется только когда числовой показатель извлечён неверно или отчёт содержит уточнённое значение, которое нельзя надёжно применить автоматически.

Перед сохранением оператор видит машинное и текущее эффективное значения. Причина обязательна. Исходный документ, машинное извлечение и предыдущие исправления не изменяются.

## Порядок работы

1. Откройте раздел «План / факт».
2. Выберите сотрудника, направление или период.
3. Откройте карточку поручения.
4. В строке показателя нажмите «Исправить план» или «Исправить факт».
5. Укажите новое число, причину и сотрудника, выполняющего исправление.
6. Проверьте пересчитанные процент исполнения, отклонение и общий прогресс.

В журнале показываются все версии. Отмена активного исправления возвращает предыдущее действующее значение, а при его отсутствии — машинный результат.

## Сохранённые представления

Набор фильтров можно сохранить как личное или общее представление. Сохраняются режим выборки, сотрудник, диапазон дат, направление, состояние и период.

Повторное сохранение под тем же названием обновляет существующее представление. Личные представления доступны их владельцу. Общие представления видны всей кафедре.

## Экспорт

Кнопка «CSV» выгружает таблицу в UTF-8 с разделителем `;`. Файл содержит:

- поручение и исполнителей;
- срок, состояние, риск и прогресс;
- показатель, план и факт;
- машинные и эффективные значения;
- признак ручного исправления и причину.

Кнопка «JSON» выгружает полную структуру выборки, историю применённых значений и итоговую сводку. Оба формата используют текущие фильтры экрана.

## Контроль целостности

Журнал исправлений является добавочным. Для каждого показателя действует не более одной активной корректировки одного вида. Связи замены фиксируются атомарно в транзакции. Удаление поручения удаляет относящийся к нему журнал, но обычные операции интерфейса записи журнала не удаляют.

## Проверка после обновления

После установки версии выполните:

```bash
npm run migrate
npm run check
npm test
npm run smoke
```

Затем проверьте сквозной сценарий:

```text
поручение с числовым планом
→ отчёт с фактом
→ подтверждение руководителем
→ исправление факта с причиной
→ экспорт CSV и JSON
→ отмена исправления
```
