# Безопасность

Проект предназначен для внутреннего контура. Не публикуйте реальные документы кафедры, персональные данные, дампы базы, ключи и журналы обработки в GitHub.

Об обнаруженной уязвимости следует сообщать владельцу репозитория непубличным каналом. Публичную задачу создавайте только после удаления эксплуатационных деталей и персональных данных.

## Границы текущей версии

Версия `0.1.0-alpha.1` является архитектурным основанием, а не завершённым средством защиты информации. Перед вводом в эксплуатацию обязательны целевые проверки Astra Linux, разграничение доступа, журналирование, резервное восстановление и проверка файлов антивирусным шлюзом.
