# Motion — Успеваемость 0.4.0

## Назначение

Движение используется только для ориентации при раскрытии периода, группы или детализации дисциплины. Оно не должно скрывать задержки импорта, подменять статус обработки или делать таблицу нестабильной.

## Разрешённые переходы

- раскрытие года/семестра/группы: короткий поворот индикатора и изменение высоты без bounce;
- появление импортной формы/инспектора: существующий sheet disclosure приложения;
- обновление статуса загрузки: opacity без пространственного перемещения;
- раскрытие evidence дисциплины: немедленное изменение содержимого либо короткая opacity/height transition.

Ориентир длительности — 100–160 мс. Все переходы должны быть прерываемыми повторным действием пользователя. Никаких циклических анимаций, параллакса, overshoot, full-screen motion или анимации числовых значений.

## Импорт и расчёт

Сохранение файла, анализ, импорт, пересчёт итогов и экспорт отображаются явным текстовым состоянием. Spinner допустим только как дополнительный неблокирующий индикатор; факт завершения определяется ответом API, а не окончанием анимации.

Изменение выбранных групп не перестраивает навигацию. Таблица обновляется на месте, сохраняя заголовки и положение основных контролов.

## Reduced motion

При `prefers-reduced-motion: reduce`:

- `transition-duration` и `animation-duration` для academic-компонентов вычисляются как `0s`;
- индикатор раскрытия меняет состояние без вращения;
- sheets и evidence остаются полностью понятными в статических кадрах;
- focus и aria-expanded обновляются синхронно с DOM;
- ни один сценарий не зависит от transitionend/animationend.

Playwright обязан проверить computed style desktop и mobile, а не только наличие CSS media query.

## Производительность и доступность

- не анимировать большие таблицы целиком;
- не применять layout-thrashing scroll animations;
- сохранять видимый focus ring;
- не автоматически прокручивать пользователя при частичной ошибке, если проблемное поле уже видно;
- программный переход к созданной группе допускается один раз после успешного импорта и должен уважать reduced motion;
- уведомление об ошибке остаётся доступным для screen reader независимо от движения.
