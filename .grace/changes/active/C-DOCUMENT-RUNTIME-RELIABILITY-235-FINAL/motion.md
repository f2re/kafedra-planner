# Motion contract — C-DOCUMENT-RUNTIME-RELIABILITY-235-FINAL

Transport canonicalization, connection errors, cache publication, installer rejection and repair results use no motion. Their static state contains the complete meaning.

The existing connection busy state may use only a 120–180 ms opacity/background transition. It must not resize controls, move content, fabricate percentage progress or delay cancellation, focus or error handling. Bounce, shake, scale pulse and blur are prohibited.

With `prefers-reduced-motion: reduce`, status and busy states switch immediately. No operation waits for an animation event. Terminal install stages are ordered text lines and exit status only; no spinner or time estimate is added.
